# Branding Assets

- `store_capsule.png` is the wide release/store artwork.
- `../../assets/branding/game_icon.png` is the square runtime and Windows application icon.

Both assets were generated with OpenAI's built-in image-generation tool for this project, then copied into the repository without modifying the original generated files.

## Production prompts

### Game icon

Create a square, text-free, polished low-poly emblem for *Don't Look Human*: one suspicious but charming gray pigeon glancing sideways in a simplified park at dusk, with a distant ranger silhouette. Use forest green, muted gray-blue, warm gold, purple, and orange; maintain a strong centered silhouette with generous padding and readability at 32 pixels. Avoid photorealism, extra birds, weapons, gore, branding, and watermarks.

### Store capsule

Create wide low-poly key art for *Don't Look Human*: a suspicious gray pigeon hiding at the right of a warm dusk park while a ranger searches in the background. Use cinematic forest green and golden light, strong thumbnail readability, and render only the exact cream uppercase title `DON'T LOOK HUMAN` in the upper-left. Avoid photorealism, weapons, gore, other logos, and watermarks.
